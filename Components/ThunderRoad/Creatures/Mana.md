# Mana

{: .important}
This component **must** be attached to your main [Creature]({{ site.baseurl }}{% link Components/ThunderRoad/Creatures/Creature.md %}) component on the same gameObject!

The Mana component is required if you want your custom [Creature]({{ site.baseurl }}{% link Components/ThunderRoad/Creatures/Creature.md %}) to be able to cast spells, use skills or merge sorcery. This component sets itself up and does not need to be edited in the inspector.
