# Equipment

The Equipment component is used to store information about a [Creature's]({{ site.baseurl }}{% link Components/ThunderRoad/Creatures/Creature.md %}) holders, worn items and holstered equipment.

![Inspector]

| Field | Description |
| :--- | :--- |
| canSwapExistingArmour | Whether the creature can manually or automatically remove armour |
| equipWardrobesOnLoad | Whether to equip all wearable items when this script loads |
| armourEditModeEnabled | Whether the white outline is enabled or not, this controls whether you can take armour off manually |
